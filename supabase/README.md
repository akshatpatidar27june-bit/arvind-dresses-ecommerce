# Supabase setup

1. Create a Supabase project for Arvind Dresses.
2. Open **SQL Editor**.
3. Paste and run `schema.sql`.
4. Create a Storage bucket named `product-images` for product photos.
5. Add the Supabase project URL and public anon key to the Next.js environment variables.
6. Keep service-role credentials server-side only.

The schema supports products, categories, customers, orders, order items, coupons, stock, sizes/colors, product images and Blue Dart tracking numbers.
