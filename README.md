# Arvind Dresses — E-commerce

Modern full-stack e-commerce platform for Arvind Dresses, Mandsaur.

## Planned modules

- Customer storefront
- Product catalogue with variants, sizes, colors and stock
- Search and category filters
- Cart and checkout
- Customer orders and order status
- Razorpay payment integration
- Blue Dart AWB/tracking support
- Admin dashboard
- Product and inventory management
- Coupons, offers and banners
- Supabase database and storage
- Vercel deployment

## Development

```bash
npm install
npm run dev
```

The current repository contains the first responsive storefront foundation. Backend, database schema, authentication, cart, checkout and admin modules will be added in subsequent phases.
